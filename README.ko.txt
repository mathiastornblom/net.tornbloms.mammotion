Homey에서 Mammotion 로봇 잔디깎이(Luba 2, Luba 3)를 제어하고 모니터링하세요. 작업을 시작, 일시정지, 정지하거나 충전소로 복귀시키고, 칼날 높이와 작업 속도를 즉시 조정할 수 있습니다. 기기 타일이나 Flow에서 바로 전조등, 사이드 LED, 우천 보호를 켜고 끌 수 있습니다.

중요: Mammotion은 계정당 하나의 활성 로그인만 허용하므로, 메인 계정을 직접 연결하면 모바일 앱에서 로그아웃됩니다. 대신 Homey용으로 무료 보조 Mammotion 계정을 사용하세요 — 설정 마법사가 계정 생성과 잔디깎이 공유를 안내해 드립니다. 약 2분이 걸리며 한 번만 하면 됩니다.

배터리 수준, 배터리 사이클, 칼날 마모, 작업 면적과 진행률, WiFi/Bluetooth 신호, GPS 위성 수, RTK 위치 정확도를 실시간으로 확인하고 Insights에서 추적할 수 있습니다.

기본적으로 클라우드를 통해 연결되며, 잔디깎이가 범위 내에 있을 때는 자동으로 직접 블루투스 연결로 전환되어 더 빠르고 로컬화된 제어가 가능합니다. Flow 카드를 사용하여 사용자 지정 칼날 높이와 속도로 작업을 시작하거나, 작업 시작 또는 종료 시 알림을 받거나, 배터리 부족 및 오류 상태에 반응할 수 있습니다.

Mammotion 앱에서 이미 설정해 둔 작업을 "작업 시작" 카드로 Flow에서 바로 실행할 수 있습니다 — 앱에서 설정한 구역, 칼날 높이, 속도, 작업 각도가 그대로 적용됩니다 — 또는 "구역 작업 시작"으로 이름이 지정된 구역 하나만 깎을 수 있습니다. "잔디깎이가 작업을 완료함"은 작업이 끝나는 즉시 실행되며 어떤 작업이었는지 알려 주므로 작업을 연달아 이어서 실행할 수 있고, "작업 재개"는 일시정지된 작업을 멈춘 지점부터 이어서 진행합니다. 팁: Mammotion 앱에서 해당 작업의 일정을 일시정지해 두면 Homey가 시작할 때만 실행됩니다.

개인정보 보호: 앱이 중단되면 문제를 더 빨리 해결할 수 있도록 개발자에게 익명의 기술 오류 보고서를 보낼 수 있습니다. 계정, 위치 또는 개인 정보는 포함되지 않으며 앱 설정에서 이 기능을 끌 수 있습니다.
